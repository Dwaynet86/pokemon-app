Import

Restore cards from a JSON export (or an older backup ZIP). Cards this server hasn't seen yet are looked up on TCGdex first, which can take a moment for a large file. If anything in the file is invalid, or a card can't be found, nothing is imported.

Prices aren't part of a backup. Use Refresh all prices on this page after importing.
